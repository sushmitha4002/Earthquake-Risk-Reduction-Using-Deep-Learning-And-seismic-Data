# Earthquake Risk Reduction Using Deep Learning and Seismic Data

## Project Description

This project focuses on earthquake risk reduction using seismic data and machine learning techniques. The project analyzes earthquake-related data and builds prediction models to understand earthquake magnitude.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- TensorFlow

## Dataset

The dataset contains earthquake-related information such as:

- Latitude
- Longitude
- Depth
- Magnitude
- Gap
- Dmin
- RMS

## Machine Learning Models

- Linear Regression
- Random Forest Regression

## Evaluation Metrics

The models are evaluated using:

- Mean Absolute Error (MAE)
- R² Score

## Project Files

- `code.py` – Python source code
- `earthquake dataset.csv` – Earthquake dataset

## How to Run

1. Install Python.
2. Install the required libraries.
3. Open `code.py`.
4. Run the Python program.
